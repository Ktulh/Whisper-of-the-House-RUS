# Whisper of the House — русификатор

Фанатский текстовый перевод игры **Whisper of the House** (Steam) на русский язык.
Переведены интерфейс, диалоги, задания, письма, названия и описания предметов.

> Перевод неофициальный и не связан с разработчиком (GD Studio).

| Версия перевода | Версия игры | Сборка Steam |
|---|---|---|
| 1.0.3 | 1.3.0.6 | 26070739 |

Посмотреть свою сборку: Steam → ПКМ по игре → *Свойства* → *Обновления* (Build ID).
На более новых версиях игры перевод, как правило, ставится, но новые строки остаются на английском,
а установщик об этом предупредит.

## Установка (3 шага)

1. Скачайте архив `WhisperOfTheHouse_RUS_vX.Y.zip` со страницы
   **[Releases](../../releases/latest)** (справа на странице репозитория → Releases → файл `.zip` в разделе *Assets*).
2. Распакуйте архив в любую папку (ПКМ по архиву → «Извлечь все…»).
3. Закройте игру и дважды щёлкните **`Установить перевод.bat`**.

Установщик сам найдёт игру в Steam. Если не найдёт — откроется окно, в котором нужно выбрать папку игры
(в Steam: ПКМ по игре → *Управление* → *Просмотреть локальные файлы*).

В игре должен быть выбран язык **English** — вместо английского теперь будет русский.
Если у вас русский клиент Steam, игра выберет его сама.

### Если Windows показывает предупреждение

* «Windows защитила ваш компьютер» → нажмите *Подробнее* → *Выполнить в любом случае*.
* Антивирус может насторожиться на `.bat`: установщик — это обычный текстовый скрипт PowerShell
  (`install.ps1`), его можно открыть Блокнотом и посмотреть. Никаких `.exe` в архиве нет.

## Удаление

Дважды щёлкните **`Удалить перевод.bat`** — будет восстановлен оригинальный файл.
Другой способ: Steam → ПКМ по игре → *Свойства* → *Установленные файлы* → *Проверить целостность файлов*.

## После обновления игры

Steam при обновлении может вернуть английский текст. Просто запустите `Установить перевод.bat` ещё раз.
Если в обновлении появились новые строки, они останутся на английском до следующей версии перевода.

## Что внутри

| Файл | Назначение |
|---|---|
| `Установить перевод.bat` / `Удалить перевод.bat` | запуск установки / удаления |
| `install.ps1` | установщик: ищет игру, делает резервную копию, применяет перевод |
| `Patcher.cs` | код, который вписывает русские строки в таблицу локализации игры |
| `ru.tsv` | сам перевод (ключ строки → русский текст) |

Установщик изменяет только файл `Whisper of the House_Data\resources.assets`,
предварительно сохраняя копию `resources.assets.rus-backup` рядом.

**Защита от поломок.** Перед записью установщик проверяет файл игры и отказывается работать, ничего не меняя, если:
файл повреждён или докачан не полностью; в таблице игры изменился порядок языков (русский попал бы не в тот язык);
в игре нашлось меньше 90% строк перевода (игра сильно обновилась). После записи файл перечитывается и сверяется:
изменилась только таблица локализации, все строки читаются обратно без искажений.
Резервная копия никогда не перезаписывается уже переведённым файлом, а устаревшая копия не восстанавливается поверх новой версии игры.

## Для разработчиков

Требуется Python 3.12 и `pip install UnityPy`.

```
python tools/export.py                 # выгрузить строки игры в translation/*.json (сохраняет готовый перевод)
python tools/batches.py make|merge|check  # нарезка на пакеты для перевода, слияние, проверка тегов
python tools/make_payload.py           # собрать installer/ru.tsv
python tools/build_release.py          # собрать zip для Releases в dist/
```

Тесты установщика (работают на копиях файла игры, саму игру не трогают):

```
python tools/make_test_variants.py <папка>   # сломанные копии resources.assets
powershell -File tools/test_installer.ps1 -Variants <папка> -Original extracted/original/resources.assets -Work <рабочая папка>
```

* `translation/*.json` — исходники перевода: `{"key", "zh", "en", "ru"}`; редактируется только `ru`.
* `translation/GLOSSARY.md` — глоссарий имён, мест и терминов.
* Игра использует I2 Localization; русский текст записывается в колонку английского языка
  (у русского Steam игра по умолчанию включает английский).
